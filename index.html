Set up automatic tracking

iPhone doesn't let web apps watch your location in the background, so we use two things together:

  1. Check on open: set your Home location in Settings. Every time you open this app it checks where you are: outside the radius with no trip open → logs “left home today”; inside the radius with a trip open → logs “home today”.
  2. iPhone Shortcuts automations (fully automatic): the Shortcuts app watches your home geofence and opens this app's leave/arrive link for you.

Shortcuts needs these to be https:// links to a hosted copy of this app (e.g. GitHub Pages / Netlify). A local file or http:// address won't work, and the links must be the same site you added to your Home Screen (data is saved per-site).

Step 1 – “Leave home” automation

  1. Open the Shortcuts app → tap Automation (bottom).
  2. Tap + / New Automation → choose Leave.
  3. Location: tap Choose → pick Home (or your address in Hermiston). Optionally adjust the radius to ~1 mile.
  4. Time: Any Time. Select Run Immediately (turn off “Notify When Run” if you like).
  5. Tap Next → New Blank Automation → Add Action → search Open URLs.
  6. Paste the Leave link above into the URL field. Tap Done.

Step 2 – “Arrive home” automation

  1. Automation → + → choose Arrive.
  2. Location: Home, Time: Any Time, Run Immediately.
  3. Add action Open URLs → paste the Arrive link. Tap Done.

Good to know

  • Links are safe to fire twice: a second “leave” while a trip is open (or “arrive” with no trip) logs nothing.
  • When you arrive, unmarked days between leaving and returning are filled in as full days.
  • Optional: add &t= with a date/time (ISO, e.g. 2026-10-20T06:15) to log a different date. In Shortcuts you can insert Current Date (format ISO 8601) after &t=.
  • Always glance at the Calendar and fix anything wrong — you're responsible for accurate records.
